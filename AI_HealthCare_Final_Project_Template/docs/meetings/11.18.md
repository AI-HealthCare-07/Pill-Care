# 📌 회의 아이디어 및 기획 방향

## 1. 필수 구현 기능

### 1-1. 가이드 생성
- 사용자 진료 기록 및 복약 정보를 기반으로 가이드 생성
- 개인별 건강 상태를 반영한 맞춤형 복약 및 생활습관 안내 자동 제공

### 1-2. 실시간 응답 및 질문 대응
- LLM 또는 규칙 기반 실시간 응답 제공
- 이전 대화 맥락 일부 반영
- 사용자 질문 대응 시스템 구축

### 1-3. 자료 업로드 및 텍스트 추출
- 진료 기록, 처방전, 약봉투 등의 이미지/PDF 업로드 지원
- 업로드한 자료에서 주요 텍스트 정보 자동 추출

---

## 2. RAG용 자료 데이터 범위
- 공공 기관 사이트에서 제공된 약품 관련 데이터 수집

---

## 3. 챗봇 안내 방식 및 강도

- 만들어진 질문을 **버튼 선택 방식**으로 진행하여 정해진 답변을 유도하는 형태 고려
- 명시된 복용 방법(공공기관 제공 사항만)을 바탕으로 사용자에게 간단한 가이드 제공
- 병원과 약국 방문 시 필요한 질문 가이드라인 제공

### 예시 1. 복용 안내

약품 설명서에 다음과 같이 명시된 경우:

> 1회 1~2방울, 1일 4~5회 점안합니다. 증상에 따라 적절히 증감합니다.

인터페이스에서는 **"하루 1~2방울"** 과 같은 형태로 간단하게 안내하는 방식 고려

### 예시 2. 사용자 맞춤형 질문

> 야간 운전기사(22:00~04:00 근무)입니다. 현재 고혈압 약 복용 중인데, 새로 받은 감기약의 졸음 부작용 때문에 운행에 지장이 없는 다른 약이나 복용 시간 조절이 가능할까요?
