# 📌 11.18 멘토링 내용 정리

## 1. 기획 문서 작성 순서

1. 프로젝트 개요 및 필요 기능, 추가할 기능 정의
2. 요구사항 정의서 작성
3. 요구사항 정의서를 토대로 와이어프레임 제작
4. 와이어프레임을 기반으로 ERD 기획
5. ERD를 기반으로 API 기획
6. 이후 프로젝트 진행 상황에 따라 수정 및 보완

## 2. 프로젝트 필요 데이터

- **프로젝트 기능 흐름:** OCR → RAG → LLM 순서로 진행
- **RAG에 필요한 데이터:** 의약품 관련 참고 데이터
- **OCR 학습에 필요한 데이터:** 처방전 등 인식에 필요한 데이터

## 3. 데이터가 부족할 경우

- 데이터 증강(Data Augmentation) 활용
- 국내 데이터가 부족할 경우 해외 데이터 활용도 검토

## 4. 역할 분담

- 팀원 각자의 강점과 관심 분야를 고려하여 역할 분담
- 팀장은 전체적인 프로젝트 진행 상황과 결과물 확인
- 백엔드와 AI 분야는 협업 가능

## 5. 프로젝트 변경 및 추가 사항

- 변경이나 추가가 필요한 경우 담당자 간 논의 후 진행
  - 변경 및 추가 사항은 추후 팀원들에게도 공유
- 모든 팀원이 역할을 맡을 수 있도록 업무 분배 및 관리
  - 업무에 참여하지 않는 팀원이 없도록 관리하는 것이 중요

## 6. 대용량 데이터 관리

- 실무에서는 공용 클라우드를 활용하여 데이터 관리
- 필요한 데이터가 무엇인지 먼저 확인하고, 필요한 부분만 추출하여 사용
- **예시:** 의약품 데이터 전체가 아닌 의약품 외형 정보만 필요한 경우 해당 데이터만 추출하여 사용

## 7. 프로젝트 진행 시 참고 사항

- 기능을 무리하게 늘리기보다 간단하더라도 실제 구현하는 것이 중요
- 졸음 유발 의약품(항우울제 등) 관련 안내 및 알림 제공 시 주의 필요
- 안내 내용이 공식 기록을 기반으로 한다는 점을 명시하는 것이 좋음
- 회원가입 시 개인정보 수집 및 이용 동의 필요

## 8. 차별화 기능 아이디어

- 매일 로그인 시 포인트 지급
- 키, 몸무게, 처방 정보 등을 입력하면 생활습관 가이드 생성
- 복약 날짜 및 시간 설정, 복약 여부 확인 및 알림 제공
- 특정 의약품과 함께 피해야 하는 음식 안내

## 9. 멘토링 일정 조율

- 팀원들의 가능한 시간을 확인한 후 멘토님께 전달하여 일정 조율
